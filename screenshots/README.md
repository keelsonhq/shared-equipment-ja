# スクリーンショット

詳細ページ用の画面写真の置き場所です。初版では撮影していません(公開前に撮影する)。

## 撮影予定

| ファイル名             | 画面                                | 状態                                                        |
| ---------------------- | ----------------------------------- | ----------------------------------------------------------- |
| `home.png`             | ホーム(`/`)                         | 管理者、1440×900。本日の数・要対応・本日の返却予定と予約    |
| `ledger.png`           | 機材(`/equipment`)                  | 管理者、1440×900。7 日の空き帯が見える既定の列              |
| `equipment.png`        | 機材詳細(`/equipment/[id]`)         | 期限超過で次の予約が入っている機材(サンプルの CM-0001)      |
| `reserve-dialog.png`   | 予約ダイアログ                      | 「この機材の予定」が見えている状態                          |
| `me.png`               | 自分のページ(`/me`)                 | 一般の社員(`/__keelson/dev` で「(サンプル)佐藤」に切り替え) |
| `label.png`            | ラベル印刷(`/equipment/[id]/label`) | QR 付きの資産タグ 1 枚                                      |
| `mobile-equipment.png` | 機材詳細(390×844)                   | 一般の社員。QR から開いた想定                               |

## 撮り方

1. `local.db` を消して `pnpm dev` を起動する(サンプルが新しく入る)
2. 上記の画面を開き、ブラウザの幅を合わせて撮影する
3. ローカルプレビューの黒い帯が写る場合は、撮影用に `pnpm build && pnpm start` で起動し、
   ブラウザ拡張などで信頼ヘッダ(`X-Keelson-User-Id` / `X-Keelson-User-App-Perms`)を付けて開く
