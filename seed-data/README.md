# 初期値とサンプルデータ

- `masters.json` は**初期設定**です。アプリの起動時に、種類・保管場所の一覧がまだ空のときだけ入ります
  (デプロイしたアプリにも入ります)。
- それ以外は**ローカル開発(`pnpm dev`)とテスト・画面写真の撮影専用のサンプル**です。`pnpm dev` が、
  ローカルのデータベースに機材が 1 件も無いときに入れます。デプロイしたアプリと `pnpm start` には入りません。

時刻は「今日から何日・何時」の相対値(`[日数, "HH:MM"]`、0 が今日)で持ち、投入した日を基準に計算するので、
いつ入れても「貸出中・本日返却・期限超過・本日の予約」がそろって見えます(投入した時刻によっては、本日の予約が終わっていたり、
本日返却が期限超過になっていたりします)。

| ファイル         | 内容                                                                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `masters.json`   | 種類と保管場所の初期値(初期設定。デプロイしたアプリにも入る)                                                                                                                                                       |
| `dev-users.json` | ローカルの名簿(`keelson dev serve` と SDK のローカルモードの形)。`pnpm dev` でログインする人と社員の一覧になる。先頭の管理者(`view,manage`)が既定の利用者で、ほかは一般の社員(`view`)。DB に社員としては保存しない |
| `equipment.json` | 機材 25 件。`admin` は記録上の管理者(サンプルの総務担当。名簿の先頭の管理者と同じ人)。`suspend` があれば利用停止                                                                                                   |
| `schedule.json`  | `loans`(貸出。`returned` があれば返却済み、`booking` があればその予約から借りた)と `reservations`(予約。`cancelled` があれば取消済み)。`former` は記録だけに登場する退職者(名簿に入れないので「メンバー外」になる) |
